# Medical Scheduling System

A Google Apps Script-based scheduling system for medical college departments, enabling admins and faculty to coordinate appointments and manage schedules efficiently.

## 🎯 Project Overview

This system provides a complete persistent data layer and runtime environment for managing medical department scheduling, including:
- Faculty management and role-based access control
- Schedule creation and management
- Swap request workflows
- Complete audit logging
- Google Calendar integration (ready)
- Email notifications (ready)

## 🚀 Quick Start

1. Create a new Google Spreadsheet
2. Open Apps Script editor (Extensions → Apps Script)
3. Copy the 5 script files from this repository
4. Run `initializeWorkbook()` from the custom menu
5. Add faculty members to the Faculty sheet

See [DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md) for detailed instructions.

## 📦 Components

- **SheetManager** - Singleton for data operations (append, update, query)
- **AuthService** - User authentication and role-based authorization
- **BulkUploadService** - Bulk data upload with parsing, validation, and fuzzy matching
- **Logger** - Structured logging with severity levels
- **Setup** - Initialization and testing utilities
